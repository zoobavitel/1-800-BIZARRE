# frontend/src/

React 18 source for the 1-800-BIZARRE SPA. Compiled by `react-scripts` (CRA). Routing is **hash-based** (the app reads `window.location.hash` directly in `index.js`), not React Router — `react-router-dom` is a dependency but the main shell does not use it.

## Entry & shell

| File | Role |
|------|------|
| [`index.js`](index.js) | `ReactDOM.createRoot`, mounts the app shell. Wraps everything in `AuthProvider` + `ThemeProvider` + `ProtectedRoute`. Defines page registry, hash router, AppBar, `HamburgerMenu`, and the page switcher. |
| [`index.css`](index.css), [`styles/`](styles/) | Global CSS (`styles/global.css`) + Tailwind layer. |
| [`ResponsiveTest.jsx`](ResponsiveTest.jsx) | `#test` route used for manual layout checking. |

## Subdirectories

| Path | Role |
|------|------|
| [`pages/`](pages/) | Top-level page components mounted by the hash router: `Home`, `CharacterPage`, `CharacterSheet`, `NPCSheet`, `CampaignManagement`, `AbilityBrowser`, `CharacterOptionsPage`, `SearchPage`, `RulesPage`, `PatchNotesPage`, `LicensesPage`, `AccountSettingsPage`, `NotificationsPage`, `MessagesPage`. |
| [`features/`](features/) | Feature folders for larger flows. Each has its own `components/`, `services/`, `hooks/`, `constants/`. Includes `auth/`, `character-sheet/`, `theme/`, `search/`, `dice-rolling/`. The character sheet is the heaviest — see `features/character-sheet/services/api.js` for the main `characterAPI` client. |
| [`components/`](components/) | Shell-level components used across pages: `ProtectedRoute`, `HamburgerMenu`, `UserMenu`, `FactionMode`, plus session UI under `components/session/`. |
| [`layouts/`](layouts/) | Page-frame components. |
| [`services/`](services/) | Cross-feature HTTP clients (e.g. `campaignService.js`). Most feature-scoped API calls live inside the relevant `features/<x>/services/`. |
| [`config/`](config/) | Runtime config — primarily `apiConfig.js` (API base URL, ngrok HTTPS helper, localStorage `apiBaseUrl` key). |
| [`data/`](data/) | Static / build-time data: `patchNotes.js` (generated by `scripts/generatePatchNotes.js`), `rulesNav.js`, shared exports. |
| [`utils/`](utils/) | Generic helpers — including `spaNavigation.js` (hash-route building / click handling). |
| [`lib/`](lib/) | Third-party glue / wrappers. |
| [`assets/`](assets/) | Imported images / fonts processed by webpack. |
| [`integration/`](integration/) | Frontend integration tests run by `npm run test:integration:frontend` (gated by `RUN_BACKEND_INTEGRATION=1`). |
| [`temp/`](temp/) | Scratch space. Don't commit anything important here. |

## Conventions

- **Routing**: add a new page by registering it in `index.js` (`PAGE_TITLES`, the switch statement, and `routeStateFromHash`). Use `utils/spaNavigation.js` helpers for links so back/forward works.
- **API calls**: import the base URL via `config/apiConfig.js` (`requireApiBaseUrl()`). Token auth lives in `localStorage.authToken`.
- **State**: page-local `useState` is the norm; shared state goes through context providers in `features/<x>/context/`.
- **Tailwind**: utility-first styling; component-scoped CSS only when Tailwind genuinely can't express it.
